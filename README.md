# Integration & AI Lab

Laboratorio personal donde documento mi evolución gradual hacia un perfil
de Arquitecto de Integración moderno: integración empresarial, APIs,
Event Driven Architecture, observabilidad, automatización e IA aplicada.

## Métrica de éxito
No mido esto por tecnologías aprendidas ni certificaciones obtenidas.
La métrica principal es: **días consecutivos dedicando 30-45 minutos al laboratorio.**

## Cómo avanza este laboratorio
- Un solo tema activo a la vez.
- No avanzo a la siguiente fase hasta consolidar la actual.
- Cada entrada de trabajo queda registrada en `BITACORA.md`.

## Fases (se abordan solo cuando llega el momento correcto)
1. Fundamentos (Git, VS Code, Docker)
2. API REST simple + OpenAPI/Swagger
3. Automatización con n8n
4. Kafka y eventos
5. Observabilidad
6. IA local (Ollama, Open WebUI)
7. Agentes aplicados a integración
